# Professional Portfolio

Welcome to the source code of my personal and professional portfolio. 

🌐 **Live Website:** [https://CharlyCastrejon.github.io](https://CharlyCastrejon.github.io)

## About
This repository contains the source code for my professional portfolio website, designed to showcase my experience, technical skills, and certifications in the software development and IT consulting industry. 

## Features
- **Clean & Corporate Design:** Focused on readability and professional presentation.
- **Light/Dark Mode:** fully responsive theme toggle persisted via LocalStorage.
- **Interactive Timeline:** Highlights current active roles and past experience.
- **Fast & Lightweight:** Built without heavy frameworks for maximum performance.

## Tech Stack
- Semantic HTML5
- Vanilla CSS3 (CSS Variables, Flexbox, CSS Grid)
- Vanilla JavaScript
